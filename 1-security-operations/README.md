# Domain 1 — Security Operations

**Exam Weight: 34%**

Security Operations is the largest domain of the CompTIA CySA+ CS0-004 exam.

## Learning Objectives

This section focuses on developing practical skills in:

- Security monitoring
- Security event analysis
- Log analysis
- Threat detection
- Indicators of compromise (IOCs)
- Threat intelligence
- Threat hunting
- Security controls
- Incident response
- Network and endpoint analysis

## Learning Approach

I will approach this domain through:

1. Learning the concepts
2. Analysing security events
3. Working with logs
4. Investigating indicators
5. Performing hands-on labs
6. Practising scenario-based questions
7. Documenting findings
8. Reviewing and improving
